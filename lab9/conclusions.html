Висновки

Під час виконання лабораторної роботи №2 було реалізовано серверну частину веб-застосунку та організовано роботу з базою даних MySQL. Створено окрему базу даних, яка використовується бекендом проєкту, а також спроєктовано та створено необхідні таблиці для збереження даних користувачів і пов’язаних сутностей. Було відпрацьовано основні операції роботи з базою даних: виконано SQL-запити типів SELECT, INSERT, UPDATE та DELETE, що дозволило реалізувати базовий CRUD-функціонал. У межах роботи сервер Node.js було підключено до MySQL за допомогою пакета mysql2. Реалізовано REST API на базі Express, через яке виконуються запити до бази даних. Запити тестувалися за допомогою Postman, що дозволило перевірити коректність обробки HTTP-запитів і взаємодію клієнт-сервер. Додатково було використано ORM Sequelize для спрощення роботи з базою даних та переходу від сирих SQL-запитів до об’єктно-орієнтованої моделі доступу до даних. Створено моделі User та Post, налаштовано їх синхронізацію з базою даних та реалізовано зв’язок типу One-to-Many (один користувач може мати багато записів). Це дозволило продемонструвати використання сучасного підходу до роботи з БД у Node.js застосунках. У результаті лабораторної роботи було сформовано повноцінну основу бекенду веб-застосунку з підключеною базою даних, реалізованим API та використанням ORM, що є важливим етапом у створенні повноцінних клієнт-серверних веб-систем.
