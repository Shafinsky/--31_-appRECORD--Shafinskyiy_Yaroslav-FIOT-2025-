Висновки

Під час виконання лабораторної роботи №6 було розроблено та протестовано повноцінний серверний веб-застосунок на базі Node.js та Express, який взаємодіє з реляційною базою даних MySQL через ORM Sequelize та працює у контейнеризованому середовищі Docker. У процесі виконання лабораторної роботи було: створено REST API для роботи з сутностями предметної області (користувачі, ігри, замовлення та інші) із реалізацією CRUD-операцій; налаштовано підключення до бази даних MySQL у Docker-середовищі та виконано імпорт існуючої структури і даних бази у контейнер; реалізовано взаємодію застосунку з БД за допомогою ORM Sequelize, налаштовано моделі, зв’язки та роботу з таблицями; усунуто типові проблеми інтеграції Node.js і MySQL (відмінності назв таблиць, timestamp-поля, синхронізація структури БД); реалізовано базові механізми авторизації та захисту маршрутів API; додано Swagger-документацію для тестування та перевірки працездатності endpoint-ів; перевірено роботу основних HTTP-запитів (GET, POST, PUT, DELETE) через Swagger та curl, а також виконано налагодження помилок сервера. У результаті виконання лабораторної роботи було отримано практичні навички інтеграції серверного застосунку з базою даних у Docker-середовищі, роботи з ORM Sequelize, створення та тестування REST API, а також налагодження помилок під час розробки серверної частини веб-застосунків. Отримані знання є важливими для подальшої розробки повноцінних клієнт-серверних систем.
