Висновки

Під час виконання лабораторної роботи було розроблено та досліджено REST API на базі Node.js та Express із застосуванням сучасних підходів до забезпечення безпеки, продуктивності та масштабованості серверних веб-застосунків. У процесі роботи було: створено REST API із використанням фреймворку Express та підключено базу даних MySQL через ORM Sequelize; реалізовано JWT-автентифікацію користувачів та захист API за допомогою middleware Helmet, Rate Limiter та валідації вхідних даних; виконано контейнеризацію застосунку за допомогою Docker та Docker Compose із використанням окремих контейнерів для API, MySQL та Redis; реалізовано кешування відповідей API із використанням Redis та виконано оптимізацію одного з маршрутів шляхом зменшення кількості звернень до бази даних; додано Swagger-документацію для опису та тестування REST-endpoint-ів; проведено навантажувальне тестування API за допомогою інструмента Artillery та виконано аналіз продуктивності до та після оптимізації; підтверджено підвищення продуктивності системи після впровадження кешування, що дозволило зменшити час відповіді сервера та забезпечити стабільну роботу під навантаженням. У результаті виконання лабораторної роботи було отримано практичні навички створення захищених та продуктивних REST API, використання кешування, контейнеризації та проведення навантажувального тестування веб-застосунків. Отримані знання є важливим етапом підготовки до розробки масштабованих серверних систем.
