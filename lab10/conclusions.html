Висновки

Під час виконання лабораторної роботи було реалізовано серверну частину веб-застосунку з використанням Node.js, Express та MySQL. Основна увага приділялась створенню базової системи автентифікації та взаємодії з базою даних через ORM Sequelize. У процесі роботи було: налаштовано підключення до бази даних MySQL та створено модель користувача; реалізовано реєстрацію користувача з валідацією даних та хешуванням пароля за допомогою bcrypt; реалізовано авторизацію користувача з перевіркою облікових даних; впроваджено JWT-автентифікацію (access та refresh токени); створено middleware для захисту приватних маршрутів; виконано тестування роботи API за допомогою Postman; досліджено процес синхронізації моделей із базою даних та використання міграцій для зміни структури таблиць. У результаті лабораторної роботи було отримано практичні навички розробки REST API, роботи з ORM Sequelize, організації безпечної автентифікації користувачів та налагодження взаємодії між сервером і базою даних. Створена система є базовою основою для подальшого розширення функціоналу застосунку (підтвердження email, OAuth, керування ролями користувачів тощо).
